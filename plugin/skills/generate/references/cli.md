# elevenlabs-cli reference (one line per subcommand)

Global: `--json` (structured stdout where supported), `--yes` (skip the spend confirmation), `--config PATH`, `--version`. Estimates and progress go to stderr; results and paths to stdout. Non-zero exit on every failure.

Config: `~/.config/elevenlabs-cli/config.json` or `$ELEVENLABS_CLI_CONFIG`. Keys: `api_key_env`, `api_key_file`, `output_dir` (null = relative `--out` is relative to the current directory; always pass absolute paths anyway), `default_model`, `sample_rate` (48000: the working rate for API requests, local generation, join, mix, delivery), `channels` (1: mono speech; join and mix go stereo when an input is stereo), `default_lufs` (per-clip target in join), `confirm_above_chars` (0 always ask, 100000 never), `trim_threshold_db`, `trim_margin_ms`, `verify_tolerance_ms`, `voices` (`{"en": {"alias": "id"}}`).

Formats: without `--format`, speech, dialogue and sts are requested as `wav_<rate>` (lossless), sound effects and music as `pcm_<rate>` wrapped into WAV. `--out` picks the container: `.wav`/`.flac` master, `.m4a` (AAC) for phones and podcasts, `.mp3`/`.opus` on request. Keep `.wav` for anything that goes into `join` or `mix`; deliver `.m4a`.

- `config init [--api-key-env E] [--api-key-file F] [--output-dir D] [--default-model M] [--force]`: write the file (prompts on a terminal).
- `config show` | `config get KEY` | `config set KEY VALUE` (`voices.<lang>.<alias> <id>`; `null` clears).
- `account`: tier, credits used/limit/remaining, reset date, voice slots, cloning rights. Free.
- `models`: live model list with max characters and languages. Free.
- `voices list [--search TEXT]`: the account's voices (id, name, category, labels). Free.
- `voices search [--language xx] [--gender male|female|neutral] [--age young|middle_aged|old] [--accent A] [--use-case narrative_story|conversational|informative_educational|...] [--search TEXT] [--category professional|high_quality|generated] [--featured] [--page-size N] [--preview-dir DIR]`: shared library; `--use-case` takes the API vocabulary, a theme such as "meditation" goes in `--search`; `--preview-dir` downloads each result's preview for free. Free.
- `voices sample VOICE... --out-dir DIR [--preview] [--text T] [--model M] [--language xx]`: renders a 20-second calm paragraph per voice (about 300 characters each) or, with `--preview`, downloads the account voice's preview.
- `voices add VOICE_ID --owner PUBLIC_OWNER_ID --name NAME`: add a library voice to the account (ids from `voices search`; uses a voice slot).
- `voices get VOICE [--language xx]` | `voices delete VOICE_ID`.
- `tts (--text T | --file F) --voice V [--model M] [--language xx] [--format mp3_44100_128|wav_44100|pcm_44100|opus_48000_128|...] [--stability S] [--similarity S] [--style S] [--speed S] [--speaker-boost] [--seed N] --out FILE [--dry-run]`: one file; long text chunked under the model limit (paragraphs for v3, sentences with stitching otherwise). Output container from the extension (`.mp3` raw when the format is mp3; `.wav`, `.m4a`, `.opus`, `.flac` via ffmpeg).
- `clips (--text T | --file F) --voice V [--model M] [--language xx] [--format F] [voice settings] [--seed N] [--ext .wav|.m4a|.mp3|.opus|.flac] --out-dir DIR [--dry-run]`: one trimmed clip per non-empty line (`#` comments skipped) plus `manifest.json` (id, text, file, duration, kept margins, sha256, voice, model, seed, request id).
- `piece (--text T | --file F) --voice V [--model M] [--language xx] [--format F] [voice settings] [--seed N] [--lufs L] [--clips-dir DIR] --out FILE [--dry-run] [--allow-truncated]`: a timed script (text lines, `[pause <s>]` lines, `#` comments; consecutive pauses add up) rendered as ONE request (one tone, one room tone), cut at the silence the model left after each line (character alignment plus silence search), reassembled by `join` with the script's exact pauses, leading and trailing ones included; `<out>.timing.json` carries the lines. v2-class models get `<break>` tags at the pauses (capped at 3 s), v3-class a paragraph per line plus a sacrificial tail. A pause the model did not leave is an error (add a full stop, a break or a paragraph), never a cut inside speech. `--lufs` normalises the whole take before cutting. The script must fit one request. Use it for guided pieces where a series of separate requests sounds cut and mashed.
- `join [ITEM...] [--spec FILE] --out FILE [--no-trim] [--lufs L] [--rate HZ] [--channels 1|2] [--no-verify]`: items are paths, `silence:<s>` (exact gap between voiced content) and `overlap:<s>` (the next voice starts before the previous ends); spec lines `file <path> [fade=<s>]`, `silence <s>`, `overlap <s>`. A silence may open or close the spec (a lead-in or a tail, verified like any gap); an overlap may not. A timeline: every clip converted once, trimmed, faded 5 ms at each edge, placed and summed; tight gaps shrink the quiet margins; the sum stays under -1 dBFS (a static gain, recorded). Writes `<out>.timing.json` (clips, gaps, overlaps, headroom) and verifies the gaps at their positions. Gaps next to a faded bed are recorded but not verifiable.
- `noise ... [--fade-in S] [--fade-out S] [--highpass HZ]`: 0.5 s fades and, for brown/red, a 40 Hz high-pass by default (the random walk's drift would thump otherwise).
- `verify AUDIO SPEC [--tolerance-ms N]`: SPEC is a `.timing.json` sidecar (reliable: each gap measured at its position) or a spec file (weaker: silences matched in order); table of expected/measured gaps, exit 1 on a mismatch.
- `mix SPEECH --bed FILE[:GAIN_DB]... [--fade-in S] [--fade-out S] [--duck DB] [--lufs L] [--rate HZ] [--channels 1|2] --out FILE`: beds looped or cut to the speech length, faded, set to their gain (default -18 dB), optionally ducked under speech, summed. Last step of an export; run after join and verify. App content keeps beds separate.
- `measure FILE... [--timing SIDECAR] [--text T]`: duration, sample rate, channels, integrated LUFS, true peak, loudness range, characters per second with `--text`, and the gap table with `--timing`. The first command to run when something sounds wrong.
- `music --prompt P --seconds S [--instrumental] [--seed N] [--format F] --out FILE`: Eleven Music, stereo at the working rate. Billed per generation.
- `dialogue (--text T | --file F) --speaker "NAME=VOICE[,model=M,stability=S,speed=S,similarity=S,style=S]"... [--mode per-turn|segments|single] [--model M] [--language xx] [--format F] [--stability S] [--seed N] [--lufs L] --out FILE [--dry-run] [--allow-truncated]`: lines `Name: text`, optionally starting with `[gap 1.2]`, `[quick]` or `[overlap 0.4]`. `per-turn` (default): one request per line with the speaker's own model and settings, placed by the seeded turn policy (question 0.10..0.30 s, short reply 0.10..0.25, long statement 0.35..0.70, same speaker 0.40..0.80, else 0.15..0.45). `segments`: the v3 dialogue endpoint's single stream cut at its voice segments and re-timed the same way. `single`: the endpoint's output untouched. Writes `<out>.timing.json` (mode, seed, gaps, overlaps) and verifies the gaps. `--dry-run` prints the turn plan with the reason for each gap.
- `voices audition --use-case UC --protocol isolation|longform|contrast --voices V... [--grid single|default|wide] [--models m1,m2] [--language xx] [--lufs L] [--dry-run]`: renders each voice on the lab protocol per grid setting; saves `samples/<voice-id>/<trial-id>.m4a` and `.json` with measurements in the lab (the config directory). `voices rate TRIAL_ID 1..5 [--note]`, `voices shortlist --use-case UC [--language xx]`, `voices index`.
- `models --diff`: live model list against the CLI's table (new, gone, changed limits). `config upgrade`: add keys a newer CLI introduced.
- `sfx --text T [--duration S] [--prompt-influence P] [--loop] [--format F] --out FILE`: billed per generation.
- `noise --color white|pink|brown|red|blue|violet --seconds S [--amplitude A] [--rate HZ] [--channels 1|2] [--seed N] [--lufs L] --out FILE`: coloured noise generated locally with ffmpeg (red = brown; stereo uses two independent generators). Free. For beds (`mix`) or as `join` items.
- `stt FILE [--model scribe_v1] [--language xx] [--diarize] [--speakers N] [--audio-events] [--out FILE]`: text (speaker-labelled paragraphs with `--diarize`) or full JSON with `--json`. Billed per audio hour.
- `isolate FILE --out FILE`: billed per audio minute.
- `sts FILE --voice V [--model eleven_multilingual_sts_v2] [--format F] [voice settings] [--seed N] [--remove-noise] --out FILE`: billed by input duration.
- `voice design --description D [--text T] [--model eleven_multilingual_ttv_v2|eleven_ttv_v3] [--seed N] [--guidance G] [--loudness L] --out-dir DIR`: previews plus their `generated_voice_id`s.
- `voice create --name N --description D --generated-id ID`: save a preview as a voice.
- `voice clone --name N --sample FILE... [--description D] [--remove-noise]`: instant clone (a voice slot).
